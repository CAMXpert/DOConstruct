# DOConstruct 操作手册

## 安装与更新

直接运行新版安装包即可覆盖更新，不需要先卸载。安装程序识别原安装目录、沿用快捷方式选项，必要时提示关闭正在运行的旧版。API 设置、聊天记录和你自己的文档项目不在覆盖范围内。更新完成后从原快捷方式打开即可。

## 查看PDF成品

打开项目后直接点右侧「PDF成品」标签。第一次会在后台组稿并生成PDF，然后在软件里显示；不需要先用「导出PDF」另存一次。内容、字体或样式改动后，再点击成品标签会更新；输入和普通保存不会自动运行排版。已有有效成品时直接切换查看，不重复打印。

「导出PDF」用于把同一份成品保存到你选择的位置，包括当前项目目录。右上角「↗」在系统阅读器中打开成品；如果系统打不开，会显示实际错误。生成期间可取消，失败保留上次成功结果，不会把自己的PDF输出当成源稿改动。

## 从空白开始

点击「新建」，输入标题，选择空白骨架、论文、专利或示例，再选一个空文件夹。论文和专利只是可修改的起始清单，不要求一开始定好全部章节。

左侧「文章骨架」的 ＋ 添加章节：填写标题和正文相对路径，例如 `content/introduction.md`。文件不存在会创建；已有文件直接引用，保留内容。每章的 ✎ 可改标题和路径，↑/↓ 调整顺序，复选框决定是否组稿。− 只移除骨架引用，不删原文。保存后重开仍保留骨架。

## 文件、图片与编辑区

「文件」标签是项目文件树，展开文件夹才读取内容；图片、正文、脚本都在这里。按钮支持新建文件/文件夹、重命名或移动，以及移到 `.doconstruct/trash/` 回收区。重命名会同步骨架及布局路径；正文中的任意图片链接仍须按内容修改。

点击正文或脚本进入彩色编辑器；点击图片在编辑区查看。默认自动换行，标题栏可切换。拖动侧栏、预览、AI 和日志边界可调整大小，软件记住尺寸。

文件名前有分类彩色图标，区分 Markdown、图片、Python、JavaScript、CSS、JSON、PDF、文件夹及普通文件。

外部程序或 AI 修改文件后，当前干净内容自动读回，骨架及展开目录同步更新。有未保存编辑时，保留缓冲并提示冲突；可读取外部版本，或保留编辑后合并/另存。此过程不运行排版。

## 修改排版

点击「排版工作台」，直接编辑当前脚本、CSS 或项目 JSON，也可修改使用的路径。默认 `layout.py` 从标准输入读 JSON，其中包含标题、章节 HTML 和 CSS；向标准输出打印完整 HTML。脚本错误显示在日志，保留上次成功预览。

「字体与版式」设置字体、字号、纸张、行距及页边距；细节在 CSS 中修改。只有点击「更新预览」/F5 或「保存版式并更新预览」才执行布局。普通输入、保存、文件刷新和 AI 修改都不执行。PDF 复用有效预览，过期时才构建一次。

「脚本命令」可配置原有组稿/出版脚本的参数数组和产物路径。`{python}`、`{pandoc}`、`{node}` 可调用随包运行时。

## AI 工作助手

1. 点击「AI 助手」→「API 设置」，填服务商 API Base URL、模型和 Key，选择 Chat Completions 或 Responses 协议。端点须支持工具调用；本地兼容模型可不填 Key。Key 使用系统加密保存。
2. 选择随包的「论文与专利写作」技能，或一般文档协作，不依赖本机安装 Codex。
3. 发送任务，例如「先读取项目，把方法章拆成两章，保留数据和引用，再检查骨架」。可勾选当前文件作为初始上下文。
4. 助手会实际查询目录、读取文件、保存修改、更新骨架并校验。工具记录显示执行情况，不用手工粘贴聊天回答。
5. 可停止任务或撤回上一轮 AI 修改；若文件随后又被修改，撤回会报告冲突，避免覆盖新版本。
6. 修改后的内容自动出现，成品预览保持原状；确认后点「更新预览」。在 AI 连接设置中勾选命令权限并保存后，助手可执行带参数的命令或 PowerShell，不需要预先配置项目命令；也可继续使用原有的已配置命令。权限关闭时无法调用这些工具。

命令执行记录显示实际命令、工作目录、输出及退出结果，可以用「停止」终止任务与子进程。`{python}`、`{pandoc}`、`{node}` 对应软件随包运行时。命令具有当前 Windows 用户权限，工作目录不是文件系统沙箱。让 AI 修改正文时优先使用文件工具，以便查看红绿差异并撤回；通过命令修改的文件不保证可撤回。命令修改文件后内容会自动读回，排版预览不会自动重跑。

### 执行中追加指令（steer）

AI运行时输入框仍可用，发送按钮变成「追加指令」。输入补充要求或纠正方向后点击它，消息先标「等待套用」，送入下一次模型推理时标「已送入推理」，仍属于原任务。已经开始的操作先完成，尚未执行的旧工具调用会跳过，再由AI按新要求判断；不会自动撤销已经完成的修改。需要立即中断正在执行的命令时使用「停止」。

勾选附上当前文件时，追加的是磁盘上已保存的内容，不会为追加指令自动保存全部文件。原任务恰好结束时会保留输入并提示重新发送；取消/失败后尚未送入推理的指令标为未套用。

每个任务默认允许100轮工具推理，旧版16轮设置自动提升。相同操作连续出现相同失败5次时，停止无效重复并说明原因；更换操作、成功执行或追加指令后重新判断。达到100轮保护上限时已完成修改保留，可以继续发送任务。

### 会话、长对话与快捷操作

AI面板顶部可新建或选择会话。每个工作区保存自己的会话列表与上次选择，重新打开工作区即可恢复；聊天、修改比较与撤回记录按会话分开。会话共享同一个文档目录，因此切会话不会还原文档；要改另一件文档请打开另一个工作区。正在执行时须先停止，才能新建或切换会话，避免将结果误归到其他会话。旧版聊天自动导入“原有会话”，旧记录文件保留。

点击会话下拉旁「改名」，输入名称后按Enter保存，Esc取消。手动名称会持久保存，不改变会话身份、聊天或修改记录；AI运行中也可改名，无须停止任务，首条指令不会覆盖手动名称。

对话默认显示最新100条，点「载入较早讯息」向前翻页并保住阅读位置。往上阅读时不会被新输出拉到底；出现新内容可点「查看最新」恢复跟随。完整聊天保存在本机；新任务送给模型的历史上下文取最近80条，不表示模型永远记得全部旧对话。一次任务内的工具记录与追加指令继续按执行顺序传递。

每则消息下有「复制」，复制原始Markdown；代码块可单独复制。用户消息的「编辑」只将文字放回输入框，不删除历史或回滚文件。最后一则AI回复可「重新尝试」，重新执行最近的用户要求，已经完成的文件修改仍然保留。执行中的「追加指令」和「停止」继续可用。

### 工作范围和权限

打开工作区后，进入「AI助手 → API设置 → 目前工作区权限」。可以分别允许读取、修改文件/骨架、执行本机命令，并用相对目录或文件逐行指定文件工具范围。例如填 `content` 和 `assets` 只允许这些位置；`.` 表示整个工作区，留空表示没有授权文件范围。这些设置只作用于当前工作区，其他工作区独立保存。新工作区默认可读写工作区文件，命令关闭；旧记录迁移时保留原有命令授权。

只读或局部范围下不能同时启用本机命令，因为PowerShell或外部程序具有当前Windows用户权限，无法靠工作目录限制其文件和网络访问。要启用命令，需明确允许读写及整个工作区文件范围；这仍不是操作系统沙箱。API设置会明确显示这一点。API连接和Key在本机共用，Key保持系统加密，文件工具不能读取隐藏凭证。没有打开工作区时仅配置模型连接，不能给未选定的工作区授权。

排版预览依旧由「更新预览」按钮触发，AI不会因普通消息、文件修改或换会话而运行组稿脚本。

保存、生成及复制成功的普通通知会在3秒后自动消失，不需手动关闭；实际错误和未保存修改确认继续显示，避免重要信息被自动隐藏。

对话以角色标签和气泡位置区分双方；AI 回答按 Markdown 显示标题、列表、表格和代码块。执行记录可收合并独立滚动，不占满对话区域。

差异计算按需运行。极复杂差异超过计算时间时，会明确显示完整双栏内容供查看，不用近似结果冒充精确增删标记。

点击「查看修改」选择任务和文件，查看真正写入的改前/改后快照。差异视图中新增行以绿色背景与＋标记、删除行以红色背景与－标记显示；代码文字保留对应语言语法高亮。可切换完整前后内容。新建文件及骨架配置同样记录，最近12轮修改保留到重启后；撤回后记录仍显示并注明已撤回。后续人工编辑不会改写这些快照，撤回也不会覆盖版本不匹配的文件。

API 服务商会收到对话、选中的技能及助手按需读取的文件。连接和 Key 由用户配置，软件不附带付费模型额度。

## 项目与自动化

`doconstruct.json` 是唯一有序骨架。旧 `sections.json` 可导入；资料、图表、工作备注不会被自动拼进正文。普通文件可被其他编辑器和 Agent 操作，文件监听会更新界面。开发接口见 [AI_HARNESS.md](AI_HARNESS.md)。
