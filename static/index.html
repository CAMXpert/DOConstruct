排版工作台
正文 → Pandoc 章節 HTML → Python 排版腳本 + CSS → 成品 HTML / PDF。修改後保存；只有點擊「更新預覽」才運行。
腳本怎麼寫？
腳本從標準輸入讀取 JSON：title、style、sections（每項 id / title / html）、css、baseUrl。將完整 HTML 寫到標準輸出；診斷寫到標準錯誤。不必重新處理 Markdown。
import json, sys
context = json.load(sys.stdin)
body = "\n".join(s["html"] for s in context["sections"])
print("<!doctype html><html><head><style>" +
      context["css"] + "</style></head><body>" + body + "</body></html>")
